# צ׳ק ליסט עבודה במעבדה (Lab Checklist Web App / PWA)

אפליקציית רשת אינטראקטיבית (PWA) בעברית מלאה (RTL) לניהול ימי מחקר ועבודה שוטפת במעבדה, מותאמת למובייל, אייפד ומחשב — כולל עבודה אופליין מלאה ושמירה מקומית בדפדפן.

## מבנה הקבצים
- `index.html` — מבנה האפליקציה והגדרות iOS / PWA
- `styles.css` — עיצוב רספונסיבי מותאם RTL והדפסה
- `app.js` — לוגיקת הצ׳ק ליסט, מעבר בין טאבים (ימי מחקר / עבודה שוטפת), סינון קבוצות (קבוצת הכוח / CR & TRE), ושמירה אוטומטית ב-`localStorage`
- `manifest.json` — הגדרות התקנה למסך הבית באייפון, אייפד ואנדרואיד
- `sw.js` — Service Worker לעבודה אופליין מלאה (גם בחדרי MRI ללא קליטה)
- `icon-180.png`, `icon-192.png`, `icon-512.png` — אייקונים לאפליקציה (180 לאייפון / אייפד)

## העלאה ל-GitHub Pages (חינם וללא צורך בשרת)
1. צרו Repository חדש ב-GitHub (למשל `lab-checklist`).
2. העלו את כל הקבצים שבתוך התיקייה ל-root של ה-Repository.
3. היכנסו ל-**Settings** -> **Pages**.
4. תחת **Build and deployment** -> **Source**, בחרו **Deploy from a branch**, בחרו את ה-branch הראשי (`main`) ואת התיקייה `/ (root)` ולחצו **Save**.
5. לאחר כדקה יתקבל קישור חי (`https://<username>.github.io/lab-checklist/`).
6. **התקנה באייפון / אייפד:** פתחו את הקישור ב-Safari -> לחצו על כפתור השיתוף -> **הוסף למסך הבית (Add to Home Screen)**.

## איפה נשמרים הנתונים
כל משתמש שומר את הנתונים שלו **רק במכשיר שלו** (localStorage בדפדפן). אין שרת ואין חשבונות — כל אחד שפותח את הקישור מקבל צ׳ק ליסט נקי משלו.
בתחתית האפליקציה יש כרטיס **"הנתונים שלך"** לשמירת קובץ גיבוי (ל-Files / iCloud / מייל) ולשחזור ממנו, למשל במעבר למכשיר חדש.

## עדכונים
ה-Service Worker מנסה קודם את האינטרנט ורק אם אין קליטה משתמש בעותק השמור — כך עדכונים שמעלים מגיעים לכולם מיד, והאפליקציה עדיין עובדת אופליין.
